The CNodeDelete path without a PTE lock (stpost / invj `inv_pathsKFU4`) is stated over `IoRS`, which holds every
region-`.none` word, the leaf page-table entries `K.ptes` included. For the PTE cut (`AvoidP`) its accepted runs
must run on a store answering only the words off `K.ptes`. Scripted copies:

* `unmap_nopG`, `frNo_ofG`: InvVs's `unmap_nop` / `frNo_of` for any walk read set `V`;
* **`delAccN`**: stpost's `delAcc` for any read set `R` with the `IoRS` words off a set `X` of `VsW` words (`hR`)

  only upper-level entries (no leaf), the read conversions are invj's `delAccX`;
* **`delFinN`**: stpost's `delFin` with `FinOK` over `IoRSR`.

Heartbeats: `delAccN` 2M (as `delAcc`), `delFinN` 4M (as `delFin`). No named premise. New module.
